# Artwork provenance

The current in-app Navrang wordmark comes from artwork supplied by the owner. The transparent PNG preserves the source foreground RGB pixels and lettering. Only the beige background, gray bottom strip and green border artifact were removed through an owner-approved alpha-mask extraction. The source already clips the lowest swashes; no missing artwork was invented.

- Supplied JPEG SHA-256: `c071cf22c9cb22383e4955b58bff0bd4a4f1691704cf398a67b11fa39b8d4916`
- Transparent PNG SHA-256: `e2356c668cf4199af0ba48e734ace438df3279ef3d27686e884b6352d239ad3f`
- Transparent dimensions: 2048 × 861 pixels

The original 512-pixel square app icon remains archived unchanged and is retained as the Android launcher icon. Its SHA-256 is `b3c9bec6b50d466c244e5b127b87cace038a16d3a236303f4b141e5ea285de9a`. The older 192-pixel drawable is a distinct historical asset. The square mark is owner-approved generated/edited artwork, not independently verified as official institutional artwork.

Existing transparent university vector marks and dancer artwork remain intact. These marks are not relicensed by the repository's MIT software license.
